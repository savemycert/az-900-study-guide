# AZ-900 Glossary

118 AZ-900 terms and services, each in one plain-English sentence.

## A

- **Access tier**: The hot, cool, cold, or archive setting that balances storage cost against access cost for blobs.
- **Action group**: The set of actions, such as email, SMS, or a webhook, that an alert runs.
- **Application Insights**: The Azure Monitor feature for application performance monitoring of web apps.
- **Archive tier**: The cheapest blob tier, offline, with retrieval that takes hours.
- **ARM template**: A JSON file that declares resources for Azure Resource Manager to deploy.
- **Audit effect**: A policy effect that reports non-compliant resources without blocking them.
- **Availability set**: A way of spreading VMs across separate hardware so one fault or maintenance event does not stop them all.
- **Availability zone**: A physically separate datacenter group within a region with independent power, cooling, and networking.
- **AzCopy**: A command-line utility for fast, scriptable bulk transfers into and out of Blob and File storage.
- **Azure Advisor**: A free service that suggests improvements to your existing resources in five categories: cost, security, reliability, operational excellence, and performance.
- **Azure App Service**: A PaaS service that runs your web apps and APIs while Azure looks after the servers.
- **Azure Arc**: A service that extends Azure management and governance to resources running outside Azure.
- **Azure Blob Storage**: Object storage for unstructured data such as images, video, and backups.
- **Azure CLI**: A cross-platform command-line tool whose commands start with `az`.
- **Azure Cloud Shell**: A browser-based, already-authenticated shell with Bash or PowerShell and the Azure tools preinstalled.
- **Azure Container Instances (ACI)**: A service that runs a single container quickly with no servers to manage.
- **Azure Data Box**: A rugged physical device Microsoft ships to you for moving large amounts of data offline.
- **Azure Disk Storage**: The disks attached to Azure virtual machines.
- **Azure DNS**: A service that hosts domain names in Azure and resolves them to addresses.
- **Azure ExpressRoute**: A private, dedicated connection to Azure that does not travel over the public internet.
- **Azure File Sync**: A service that mirrors an Azure Files share to an on-premises Windows file server, which acts as a local cache.
- **Azure Files**: Managed file shares that you mount over SMB or NFS.
- **Azure Functions**: Serverless, event-driven compute that runs code on a trigger and bills per execution.
- **Azure Government**: A sovereign Azure cloud for US government agencies and their partners.
- **Azure Hybrid Benefit**: A way to reuse existing Windows Server or SQL Server licenses to lower Azure costs.
- **Azure Kubernetes Service (AKS)**: A managed service that orchestrates many containers at scale.
- **Azure Migrate**: A central service for assessing workloads and moving servers, databases, and apps into Azure.
- **Azure Monitor**: Azure's end-to-end monitoring platform that gathers metrics and logs from your apps and infrastructure for analysis.
- **Azure Monitor alerts**: Rules that notify you or trigger an action group when a metric or log condition is met.
- **Azure Policy**: A service that evaluates resources against rules and can audit or deny non-compliant ones.
- **Azure portal**: The web-based GUI for creating and managing Azure resources.
- **Azure PowerShell**: PowerShell modules of Verb-Noun cmdlets for managing Azure.
- **Azure Pricing Calculator**: A free tool for estimating the monthly price of planned Azure services.
- **Azure Queue Storage**: A store for messages passed between parts of an application.
- **Azure region**: One or more datacenters in a geographic area, joined by a low-latency network, where you deploy resources.
- **Azure Reservations**: A discount in exchange for committing to a specific resource for 1 or 3 years.
- **Azure Resource Manager (ARM)**: The deployment and management layer that handles every request to create, change, or delete resources.
- **Azure role-based access control (RBAC)**: Assigning roles at a scope so users get only the permissions they need.
- **Azure savings plan**: A discount in exchange for committing to a fixed hourly compute spend for 1 or 3 years.
- **Azure Service Health**: A personalized view of Azure service issues, planned maintenance, and health advisories affecting your resources.
- **Azure Spot Virtual Machines**: Discounted VMs on spare capacity that Azure can evict when it needs the capacity back.
- **Azure status page**: A public page showing the global health of Azure services, not tailored to any customer.
- **Azure Storage Explorer**: A free desktop app for browsing and transferring storage data through a GUI.
- **Azure Table Storage**: A NoSQL key-value store for structured, non-relational data.
- **Azure Virtual Desktop**: A service that delivers Windows desktops and apps from Azure to users anywhere.
- **Azure Virtual Machines**: Azure's IaaS service for running cloud-based virtual servers whose OS you manage.
- **Azure Virtual Network (VNet)**: A private network in Azure where resources communicate securely.
- **Azure VPN Gateway**: A service that connects a network to Azure through an encrypted tunnel over the public internet.

## B

- **Bicep**: A simpler language for Azure infrastructure as code that compiles to ARM JSON.
- **Budget**: A spending threshold on a scope that triggers alerts as spend approaches or exceeds it.

## C

- **CanNotDelete lock**: A lock that allows reading and modifying but blocks deletion.
- **Capital expenditure (CapEx)**: Upfront spending on physical assets you own, such as servers, depreciated over several years.
- **Cloud computing**: Renting compute, storage, and networking from a provider over the internet, on demand and metered by use.
- **Compliance**: Being able to show that you meet internal rules and external regulations.
- **Compute**: Processing power in the cloud, such as virtual machines.
- **Conditional Access**: Microsoft Entra policies that allow, block, or add requirements to sign-ins based on signals such as location, device, and risk.
- **Consumption-based model**: A billing model where you pay only for the resources you use, for as long as you use them.
- **Container**: An application packaged with its code and dependencies so it runs the same way on any host.
- **Control plane**: A single place to manage and govern resources, wherever they run.
- **Cost analysis**: A Cost Management view that breaks spend down by service, scope, region, or tag.

## D

- **Dashboard**: A customizable portal view of pinned tiles for the resources you care about.
- **Data classification**: Scanning data and labeling sensitive information such as personal or financial details.
- **Datacenter**: A secured facility of servers, storage, and networking that makes up part of an Azure region.
- **Declarative**: Describing the end state you want and letting the platform work out how to reach it.
- **Deny effect**: A policy effect that blocks non-compliant resources from being created or updated.
- **Disaster recovery**: Bringing a service back after a large outage, usually with resources in another location.

## E

- **Egress**: Data transferred out of Azure, which is generally billed.
- **Elasticity**: Automatically adding and removing resources in real time to match demand.

## F

- **Fault tolerance**: A design where another component takes over when one fails.

## G

- **Geography**: A larger area, such as Europe, that contains regions and helps meet data-residency needs.
- **Governance**: Setting rules for cloud resources and enforcing and auditing them automatically.

## H

- **High availability**: Designing so an application stays reachable and downtime is kept to a minimum.
- **Horizontal scaling**: Changing the number of identical resources, also called scaling out or in.
- **Hybrid cloud**: A public and a private cloud connected so workloads and data can move between them.

## I

- **Infrastructure as a Service (IaaS)**: Rented VMs, storage, and networking where the OS, runtime, apps, and data are yours to manage.
- **Infrastructure as code (IaC)**: Defining infrastructure in files so deployments are declarative and repeatable.

## L

- **Lift and shift**: Moving an existing server to the cloud with few or no changes, typically onto IaaS.
- **Log Analytics**: The Azure Monitor tool for querying log data with Kusto Query Language (KQL).
- **LRS / ZRS / GRS / GZRS**: Redundancy options that keep copies in one datacenter, across zones, in a paired region, or across zones plus a paired region.

## M

- **Management group**: A container that organizes subscriptions and passes its settings down to them.
- **Management in the cloud**: How you manage resources yourself, through a portal, command line, scripts, or APIs.
- **Management of the cloud**: The cloud managing resources for you through automatic scaling, recovery, templates, and monitoring.
- **Metrics**: Numbers recorded at intervals, such as CPU percentage, used to spot trends.
- **Microsoft 365**: A SaaS suite for email, documents, and collaboration.
- **Microsoft Cost Management**: The tool for analyzing, budgeting, and alerting on actual Azure spend.
- **Microsoft Entra Domain Services**: Managed domain features such as domain join and Kerberos without running your own domain controllers.
- **Microsoft Entra ID**: Azure's cloud identity and directory service, formerly Azure Active Directory (Azure AD).
- **Microsoft Purview**: A unified data governance and compliance service for cataloging, classifying, and discovering data.
- **Multifactor authentication (MFA)**: Sign-in that requires two or more factors from different categories.

## O

- **Operational expenditure (OpEx)**: Ongoing spending on a service you consume, billed after use.

## P

- **Pay-as-you-go**: Paying for cloud usage per period with no large upfront purchase.
- **Platform as a Service (PaaS)**: A managed platform where the provider runs the OS and runtime and you manage your app and data.
- **Policy initiative**: A group of policies assigned together as one unit.
- **Predictability**: Confidence in future performance and cost, from consistent behavior under load and metered billing.
- **Private cloud**: Cloud infrastructure used by a single organization, in its own datacenter or hosted by a third party.
- **Public cloud**: Provider-owned infrastructure shared by many organizations, each logically isolated from the others.

## R

- **ReadOnly lock**: A lock that allows reading but blocks both modification and deletion.
- **Region pair**: Two regions in the same geography, far apart, linked for disaster recovery and data replication.
- **Reliability**: The capacity of a system to keep working and bounce back when parts of it fail.
- **Resource**: A single manageable item in Azure, such as a virtual machine or storage account.
- **Resource group**: A logical container for related resources that can be managed and deleted as a unit.
- **Resource lock**: A setting that prevents a resource from being deleted or modified, for everyone, until it is removed.
- **Right-sizing**: Matching resource sizes to actual use so you stop paying for idle capacity.

## S

- **Scalability**: The ability to add or remove resources as demand changes.
- **Serverless**: A model where the provider runs your code on demand and manages all servers, billing per execution.
- **Service-level agreement (SLA)**: A provider's published commitment to the availability of a service.
- **Shared responsibility model**: The split of security and management duties between the cloud provider and the customer.
- **Software as a Service (SaaS)**: Finished software you sign in to and use, with the provider managing nearly everything.
- **Sovereign region**: An isolated Azure instance kept separate from the global cloud for strict legal or regulatory needs.
- **Storage account**: The top-level container for Azure Storage data, where region, redundancy, and performance are set.
- **Subnet**: An address range inside a VNet used to separate groups of resources.
- **Subscription**: The unit that receives the bill and bounds access, containing one or more resource groups.

## T

- **Tag**: A name-value label on a resource, resource group, or subscription used to organize and report on it.
- **Total Cost of Ownership (TCO) Calculator**: A free tool that compares the cost of an on-premises environment with running it in Azure.

## V

- **Vertical scaling**: Changing the CPU or memory of a single resource, also called scaling up or down.
- **Virtual Machine Scale Set**: A group of identical VMs whose number grows and shrinks automatically with demand.
- **Virtual network peering**: A private link between two VNets over Microsoft's backbone.

## Z

- **Zone-redundant**: A deployment spread automatically across availability zones so it survives the loss of one zone.
